Support

App support, service scope and security reporting.

Uninstall deletes saved analyses.

Uninstalling removes Profitability Analysis snapshots. Reinstalling starts empty. Recovery requires a verified backup and preserved encryption configuration. A full restore may roll back unrelated site data. Recovery is not guaranteed.

Contact

Bhushan Raut, individual developer. Email bhushanraut4343@gmail.com.

Support is normally available Monday–Friday, 10 AM–6 PM IST, excluding Maharashtra statewide public holidays. Availability may vary. No guaranteed acknowledgment or resolution time is offered.

Service scope

Standard app updates, bug fixes, installation guidance and email troubleshooting. Reporting an issue does not promise a particular fix or delivery date.

Hosting, custom development, integrations and data recovery are excluded. Unsupported versions and modified deployments require assessment. Hosting incidents may also need the hosting provider.

Report an issue safely

  • Include app/framework versions, sanitized reproduction steps and expected versus actual behavior.
  • Include relevant error messages, request status and timestamps, with secrets and private details removed.
  • Do not send passwords, API secrets, session cookies or encryption keys.
  • Obtain explicit agreement before sending sensitive financial information; agree the minimum diagnostic data and transfer method first.

Security reports

Use the same email with “Security report” in the subject. Report privately; do not put confidential records or exploit details into public issues.

Supported environment

Verified local acceptance covers Frappe/ERPNext 16.52.0 and Python 3.14.x with the documented dependencies. Separate exact-commit CI passed 145 tests on Frappe 16.56.0 / ERPNext 16.54.0; this is narrower automated validation, not full lifecycle/performance acceptance. See the documented validation scope.

Support email uses personal Gmail (Google). See the Privacy Policy. Do not uninstall or rotate encryption keys as a troubleshooting shortcut.
